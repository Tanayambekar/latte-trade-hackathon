# ☕ Latte Trade — MochaTrade Track 2 hackthon Prototype

An interactive frontend prototype engineered for the **RVCE ACM MarketSphere 2026** finance hackathon in association with **MochaTrade (YC S26)**. 

## 🚀 The Core Problem Solved
First-time retail investors frequently back out of derivative platforms due to a lack of structural trust and a misunderstanding of how self-custodial perpetual futures operate compared to traditional equity ownership. 

Latte Trade solves this bottom-of-the-funnel drop-off by shifting the onboarding paradigm from a "sketchy casino" to a **disciplined, psychologically safeguarded environment**.

## ✨ Core Features Implemented
* **AI Mindset & Intent Logging:** Forces traders to declare their trade thesis and entry/exit targets before execution to combat emotional over-trading.
* **Psychological Sentiment Tracker:** Simulates behavioral feedback loop (Calm, Anxious, Frustrated) based on user trade logs.
* **The 10-Trade Circuit Breaker:** Restricts trading and triggers a strategic reset/post-mortem if predefined risk boundaries are violated.
* **Transparent Backend Education:** Demystifies the underlying mechanics of INR-settled, self-custodial perpetual trading profiles to systematically build user trust.
